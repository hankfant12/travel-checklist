目前使用本地保存

你在手机上修改行程，老婆打开同一个邀请链接后，通常几秒内即可看到；不用反复发送文件。网页仍托管于 GitHub Pages，数据放在 Firebase。

第一步：创建免费 Firebase 项目（只需做一次）

前往 Firebase 控制台 ↗，新建项目；打开 Build → Realtime Database 创建数据库；然后到 Authentication → Sign-in method 启用 Anonymous（匿名） 登录；在「项目设置 → 你的应用」添加网页应用（</>），复制 firebaseConfig。

重要：Realtime Database 的「Rules」必须替换成下面的规则，不能一直使用开放的测试模式。确保配置里有 databaseURL（从 Realtime Database 页面复制）。

📋 展开并复制数据库 Rules
{
  "rules": {
    "rooms": {
      "$roomId": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}

该方案用不可猜测的长随机房间链接保护数据。任何拿到完整邀请链接的人都能编辑，请不要公开分享。它不是严格的家庭账号权限系统，不适合存放证件号或敏感信息。

第二步：粘贴网页应用配置

可直接粘贴 Firebase 控制台提供的 const firebaseConfig = { ... };；这段网页配置不是私钥，但请勿在这里粘贴服务账号私钥。
